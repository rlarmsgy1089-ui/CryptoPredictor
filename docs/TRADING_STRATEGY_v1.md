## 0. 한 줄 원칙

> **"Tier S 컨플루언스 존(strength≥80) + 분류기 confidence≥65 + bounce 시나리오만 잡는다. 그 외는 전부 패스."**

이 한 줄이 전략의 전부예요. 아래는 이 한 줄을 어떻게 강제할지에 대한 설명입니다.

## 1. 왜 이 전략인가 — 백테스트 근거

### 컨플루언스 존 강도별 적중률 (전체 68.4만 이벤트)

| Strength | 표본 수 | rejected_rate (bounce 성공률) | 평가 |
|---|---|---|---|
| 40-59 | 197,860 | **58.7%** | 약함 — 사용 ❌ |
| 60-79 | 412,008 | **53.1%** | **거의 랜덤** — 사용 ❌ |
| **80+** | **74,721** | **66.1%** | **사용 ✅** |

### 결정적 발견

현재 `auto_trader.minStrength = 70`은 **52% 정확도 구간을 포함**해요. 이걸 **80으로 올리면** 적중률이 **53% → 66%로 점프**합니다. 같은 R:R 1:2에서:

- 53% 승률: EV = 0.53 × 2% - 0.47 × 1% = **+0.59%/거래**
- 66% 승률: EV = 0.66 × 2% - 0.34 × 1% = **+0.98%/거래** (1.66배)

수수료·슬리피지(왕복 0.2%) 고려해도 차이가 명확합니다.

### 분류기 정확도 (방향 예측, 어제 break_fix/inside_fix 적용 후)

- bounce-up: **65.7%**
- bounce-down: **56.0%**
- ambiguous: 자동 차단 (전체의 42%)
- break-up / break-down: backtest 검증 안 됨 → 본 전략에선 **사용 안 함**

→ **"bounce 시나리오만 잡는다"** 가 핵심. break는 데이터로 검증되기 전까지 보류.

## 2. 진입 규칙 (모두 AND 조건)

### 필수 6개 조건

| # | 조건 | 값 | 근거 |
|---|---|---|---|
| 1 | 컨플루언스 존 strength | **≥ 80** | Tier S만 |
| 2 | 분류기 confidence | **≥ 65** | 캘리브레이션 후 실제 적중률 |
| 3 | 시나리오 | **bounce-up OR bounce-down** | break는 미검증 |
| 4 | 현재가 ↔ 존 center 거리 | **≤ 1.5%** | 이미 무빙 시작했으면 패스 |
| 5 | regime | **ranging OR volatile** (trending과 같은 방향이면 OK) | 추세 역행 금지 |
| 6 | 일일 손실 한도 | **-5% 미달성** | 안전장치 (이미 코드에 있음) |

### 추가 필터 (선택사항이지만 강력 추천)

- **시간대 차단**: 새벽 03:00~07:00 KST는 거래량 박약 → 신호 신뢰도 낮음. 이 시간대 진입 차단.
- **주요 경제 이벤트 ±30분**: FOMC, CPI 발표 전후는 룰 무관 패스.
- **24h 변동률 |x| > 8%**: 이미 큰 움직임 후엔 추세 추종이 더 이김 → bounce 전략 불리.

## 3. 청산 규칙

### 기본 (코드 기본값 유지)

- **SL (손절)**: 진입가 ± 1.0%
- **TP (익절)**: 진입가 ± 2.0%
- **R:R**: 1:2

### 동적 청산 — 추가 권장

| 트리거 | 액션 |
|---|---|
| 진입 후 **30분 내 +0.7%** 도달 | SL을 진입가 (BE)로 이동 → 무손실 보장 |
| 진입 후 **2시간** 경과, +/- 둘 다 0.5% 미만 | **시간 손절** — 50% 청산 |
| 다음 컨플루언스 존 도달 | 60% 부분 익절, 나머지는 trailing stop (0.5%) |
| 분류기 confidence가 **40 이하로 떨어짐** | 50% 청산 (시그널 약화) |

### 청산 우선순위

1. 일일 손실 -5% 도달 → **모든 포지션 즉시 청산 + 당일 진입 금지** (이미 코드 ✅)
2. SL/TP 히트
3. 시간 손절
4. 시그널 약화 청산

## 4. 포지션 사이징

### 기본 공식

```
포지션 크기 = 계좌 잔고 × 1% / SL%
```

**예시 (계좌 $10,000, SL 1%):**
- 리스크 금액 = $10,000 × 1% = **$100**
- 포지션 크기 = $100 / 1% = **$10,000** (1배)
- 만약 SL이 0.5%라면 = $100 / 0.5% = $20,000 (2배)

### Tier별 사이징 차등 (선택)

| 조건 | 리스크 비율 |
|---|---|
| Strength 80-89 | 0.7% |
| **Strength 90+** | **1.5%** |
| confidence 65-74 | 0.7% |
| confidence 75+ | 1.0% |
| 두 조건 모두 충족 | 1.5% (상한) |

**최대 한 번에 묶일 자본**: 동시 3개 × 1.5% = 자본의 **4.5%**.

## 5. 리스크 관리 — 안전장치 5중

| Layer | 한도 | 액션 |
|---|---|---|
| 1. 거래 단위 | SL 1% | 자동 청산 |
| 2. 포지션 단위 | 리스크 1% | 사이징 강제 |
| 3. **일일** | -5% | 당일 거래 정지 (이미 코드 ✅) |
| 4. **주간** (신규 추가 권장) | -12% | 1주일 거래 정지, 룰 재점검 |
| 5. **월간** (신규 추가 권장) | -20% | 전략 중단, 백테스트 재실행 |

## 8. 페이퍼 트레이딩 검증 (2주)

### 검증 KPI — 실전 전환 합격선

| KPI | 합격선 | 측정 방법 |
|---|---|---|
| 거래 횟수 | ≥ 30 (통계적 유의) | trades.length |
| 승률 | **≥ 55%** | wins / trades |
| Profit Factor | **≥ 1.5** | gross_win / gross_loss |
| 최대 낙폭 (MDD) | **≤ 8%** | 일일 잔고 곡선 |
| Sharpe (일간) | ≥ 1.0 | mean(daily_pnl) / std(daily_pnl) |
| 연속 손실 (max) | ≤ 5 | consecutive_losses |
| 분류기 confidence와 실 승률 상관 | 양의 상관 | confidence 버킷별 승률 비교 |

### 한 가지라도 미달이면

- **조건 강화** → minStrength 85, minClsConfidence 70 으로 더 빡빡하게
- 또는 **거래 페어 축소** → AVAXUSDT_1h 단독 운용

### 일일 점검 루틴

## 9. 실전 전환 체크리스트

### Go-Live 조건 (모두 충족)

- [ ] 페이퍼 거래 ≥ 60건
- [ ] 승률 ≥ 55%
- [ ] Profit Factor ≥ 1.5
- [ ] MDD ≤ 8%
- [ ] 연속 손실 ≤ 5
- [ ] 적어도 한 번의 약세장(BTC -10% 이상 일주일) 통과 경험
- [ ] 자동매매 알림이 끊김 없이 작동했는지 확인 (downtime 0%)
- [ ] 본인이 그 시점에 **수동 개입하고 싶지 않다고 느낌**

### 실전 전환 시 추가 안전장치

- **첫 1주**: 페이퍼 사이즈의 **20%** 만 (계좌의 0.2% 리스크)
- **둘째 주**: 페이퍼 사이즈의 **50%**
- **셋째 주~**: 페이퍼 사이즈와 동일 (1% 리스크)
- 첫 달 누적 손실 -10% 도달 → **즉시 페이퍼 복귀**

## 10. 전략 진화 로드맵

### Phase 1 (지금) — 검증된 단순 룰

✅ 현재 문서 = 이 단계

### Phase 2 (페이퍼 2주 후, 데이터 충분)

- **분류기 confidence × 페어** 별 실제 승률 분석 → 페어별 임계값 차등화
- **시간대별 승률** 분석 → 더 좁은 시간대 화이트리스트
- **regime 필터 정밀화** — 코드의 regime detector 출력을 매매 룰에 직접 연동

### Phase 3 (1개월 후)

- **break 시나리오 재검증** — 어제 break_fix 적용 후 1개월치 새 데이터 확보 → 재학습
- **Trailing TP 최적화** — 평균 max_excursion 통계로 TP 위치 최적화
- **다중 시간대 정렬** — 1h 시그널 + 4h 추세 일치 필터

## 11. 위험 고지 (꼭 읽기)

1. **백테스트는 미래를 보장하지 않음** — 합성 OHLCV 일부 포함, 실데이터 재생성 진행 중.
2. **Walk-forward 통과 페어가 1개 (AVAXUSDT_1h)뿐** — 다른 페어는 보조적으로만 사용.
3. **암호화폐는 24/7 + 변동성 높음** — 잠든 사이 SL 슬리피지 가능, 지정가 주문 권장.
4. **이 문서는 백테스트 + 코드 분석 기반의 가설** — 실전 적용 결과는 본인이 책임.
5. **모든 파라미터는 페이퍼 검증 후 조정 가능** — 한 번에 다 맞을 거란 기대는 위험.
