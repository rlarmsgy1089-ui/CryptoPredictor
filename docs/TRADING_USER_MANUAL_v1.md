## 0. 이 도구가 뭐 하는 건가요?

한 줄: **"여러 신호가 동시에 맞을 때만 매매하도록 사람을 도와주는 AI 보조 시스템"**.

매매 결정은 보통 한두 가지 신호로는 부정확해요. 이 도구는 **9개의 독립된 검사**를 통과한 셋업만 알려주고, **5개의 안전장치**로 막대한 손실을 차단합니다. 페이퍼 트레이딩으로 먼저 검증한 후 실전으로 넘어가는 흐름을 권장해요.

**도구의 한계 먼저 알기:**
- 미래를 맞추는 도구가 아닙니다 — **확률 게임을 합리적으로 하는 도구**
- 백테스트 정확도 ~63% — 100번 중 37번은 틀려요
- 가짜 돈 페이퍼 → 진짜 돈 실전 전환은 본인 책임

## 2. 처음 30초 — 시작 전 점검

페이지를 열자마자 본인이 매매해도 되는 환경인지 4초 안에 판단할 수 있어요.

### ✅ "지금 매매 가능" 신호

화면 우측 GATEKEEPER 패널이 **초록색 SAFE · GATE OPEN** 상태인지 확인:

```
GATEKEEPER                       true
🟢 SAFE · GATE OPEN

  뉴스       경제       고래
   🟢         🟢         🟢
```

세 등급(뉴스/경제/고래) 모두 🟢이면 시장이 정상입니다. 매매 진행 OK.

### 🚫 "지금 매매 위험" 신호

다음 중 하나라도 보이면 **그 시간대는 신규 진입 자제**:

- GATEKEEPER가 **빨강** ("DANGER" 또는 "BLOCKED")
- 좌측 거시 컨텍스트에 **🔴 RISK OFF** 큰 빨간 글씨
- 다음 주요 지표 **D-0 또는 D-1** (FOMC, CPI 발표 1일 이내)

이런 경우엔 그냥 **차트 구경만** 하시거나, 보유 포지션 익절/손절 관리만 하세요.

## 3. 의사결정 흐름 — 한 거래의 일생

도구를 사용하는 한 사이클은 이렇게 흘러갑니다:

```
[1단계 점검]      거시 환경 OK?
     ↓
[코인 선택]       BTC, ETH, SOL, AVAX, LINK 중 어디?
     ↓
[3단계 점검]      4H/1H/15m 멀티 TF 정렬?
     ↓
[4단계 점검]      Tier S/A 컨플루언스 존 존재?
     ↓
[6단계 점검]      Entry Trigger 활성화?
     ↓
[5+7+8단계 점검]  On-chain · AI · Gatekeeper 안 막혀?
     ↓
[9단계 EXECUTE]   최종 진입 가능 신호?
     ↓
[주문 패널]       LONG/SHORT, Risk%, SL%, TP% 입력
     ↓
[매수/매도 버튼]  시뮬레이션 페이퍼 진입
     ↓
[페이퍼 위젯]     5초마다 SL/TP 감시
     ↓
[자동 청산]       TP 또는 SL 도달 시 자동 정산
     ↓
[KPI 누적]        승률, PF, MDD에 반영
```

이 흐름의 핵심: **"단계를 하나씩 통과시키며 거르는 것"**. 처음엔 9단계를 다 보지 마시고, **1, 4, 6, 8, 9단계 5개**만 보세요.

## 4. 단계별 상세 사용법

### 1단계 — 거시 환경 (시장의 큰 흐름)

**언제 보나**: 매매 시작 전 매번. 30초 안에 확인.

**무엇을 보나**:

- **MARKET REGIME** — 🔴 RISK OFF / 🟡 NEUTRAL / 🟢 RISK ON
- **DXY** (달러 인덱스) — 100 위는 달러 강세 → 암호화폐 약세 압력
- **SPX** (S&P 500) — 주식 시장 동조성 확인
- **US10Y** (미국 10년 국채 금리) — 4% 이상이면 위험자산 부담

**초보 사용법**:
- **🟢 RISK ON + GATEKEEPER 🟢** → 매매 적극 진행 OK
- **🟡 NEUTRAL** → 매매 가능하나 사이즈 절반
- **🔴 RISK OFF** → 그날은 신규 진입 패스. 보유 포지션 관리만

**판단 예시**:
> "DXY 98.51, SPX 7165, US10Y 4.31%, 위험선호도 -36 → RISK OFF"
> → 오늘은 페이퍼만 켜놓고 데이터 쌓기. 신규 진입 안 함.

---

### 2단계 — 차트 (기본 차트 분석)

**언제 보나**: 코인 종목을 정한 후, 진입 직전.

**무엇을 보나**:
- 지지선/저항선
- 추세선
- 패턴(삼각수렴, 헤드앤숄더 등)

**초보 사용법**: 이 단계는 **참고 정보** 수준. 의사결정의 주체가 아니에요. 한 번 훑고 넘어가시면 됩니다. 어떤 패턴이 있는지 모르겠다면 **`패턴 가이드`** 버튼(상단)을 눌러 가이드 참고.

---

### 3단계 — 멀티 TF (4H · 1H · 15m 정렬)

**언제 보나**: 진입 결정 직전. 매우 중요.

**무엇을 보나**: 세 시간대(4시간, 1시간, 15분)의 추세가 일치하는지.

```
4h BULL | 1h FLAT | 15m BULL → 부분 정렬 (2/3)
4h BULL | 1h BULL | 15m BULL → FULL CONFLUENCE ✅ (강한 신호)
4h BULL | 1h BEAR | 15m BULL → 충돌 ❌ (피하기)
```

**초보 사용법**:
- **3개 모두 같은 방향** → 진입 강도 1.5배
- **2개 같은 방향, 1개 중립** → 일반 사이즈
- **1개라도 반대 방향** → 패스 (큰 시간대가 작은 시간대를 이김)

**판단 원칙**: 항상 큰 시간대(4H)의 방향과 **같은 방향**으로 진입.

---

### 4단계 — 컨플루언스 존 ⭐ (가장 중요)

**언제 보나**: 매매 결정의 주축.

**무엇을 보나**: 차트에 표시된 **가로 줄**들. 여러 신호(피보나치, 거래량 프로파일, 패턴 경계, 이평선 등)가 같은 가격대에 겹친 구간.

**Tier 등급**:
- **🟢 Tier S** (strength≥80) — **가장 신뢰할 만한 가격대 (66% 적중률)**. 이것만 노리세요
- **🔵 Tier A** (strength≥50) — 보조용
- **⚪ Tier B** (strength≥30) — 약한 신호. 사용 X

**초보 사용법** — 가장 중요한 룰:

1. 차트에 **녹색(Tier S) 가로 줄**이 있는지 확인
2. 현재가가 그 존의 **1.5% 이내**인지 확인
3. 분류기 라벨이 **"반발 ↑"** 또는 **"반발 ↓"** (bounce)인지 확인
   - "돌파 ↑/↓"는 **사용 X** (백테스트 미검증)
4. **분류기 confidence ≥ 65%** 인지 확인

**판단 예시**:
> "BTC 현재가 $78,000, 컨플루언스 패널에 '@77,800 Tier S strength=84 반발 ↑ conf=71%' 표시됨"
> → 거리 0.26%, Tier S, 반발 시나리오, conf 71% → **모두 통과**, 진입 후보

> "ETH 현재가 $4,200, '@4,150 Tier B strength=35 돌파 ↓ conf=52%'"
> → Tier B + 돌파 + 낮은 conf → **모두 탈락**, 패스

---

### 5단계 — On-chain (고래/거래소 흐름)

**언제 보나**: 4단계 통과 후, 진입 직전 보조 검증.

**무엇을 보나**: 큰 지갑들의 거래소 입출금, 분배 지수 등.

**초보 사용법** — 이 단계는 **있으면 +10점, 없어도 OK**:

- 🟢 OK → 큰손이 분산매수 신호 → 진입 가산
- 🟡 분배 (Heat ≤ 40) → 약한 부정 → 사이즈 축소
- ⚪ 데이터 없음 → 무시 (기본값)

처음에는 **그냥 무시**해도 됩니다. 핵심 결정엔 4·6·8단계가 더 중요해요.

---

### 6단계 — Entry Trigger ⭐ (진입 타이밍)

**언제 보나**: 4단계 통과 후, 들어갈 시점 잡을 때.

**무엇을 보나**: 4가지 트리거 조건의 통과 개수:
- 가격 액션 (캔들 패턴)
- 거래량 확장
- 모멘텀 (RSI, MACD)
- 멀티 TF 일치

**초보 사용법**:

| 표시 | 의미 | 행동 |
|---|---|---|
| 🚀 4/4 통과 | 모든 조건 만족 | **즉시 진입** |
| ⏳ 3/4 통과 | 1개 대기 중 | **대기 + 새로고침** |
| ⏸ 2/4 통과 | 약한 신호 | 패스 또는 더 기다림 |
| ❌ 1/4 이하 | 거의 신호 없음 | 패스 |

**판단 원칙**: **3/4 이상**일 때만 진입. 1/4은 noise.

---

### 7단계 — AI 예측 (ML 확률)

**언제 보나**: 진입 직전 마지막 보조 검증.

**무엇을 보나**: AI 모델의 방향 예측 + 확률.

```
4h UP 72%      ← 1시간 후 상승 확률 72%
1h DOWN 58%    ← 1시간 후 하락 확률 58%
```

**초보 사용법** — **참고만**:
- AI 예측이 본인 진입 방향과 **같으면** → 신뢰도 +
- 반대면 → **재검토** (패스 권장)

**중요**: AI는 보조이지 주체가 아닙니다. 4·6단계가 우선.

---

### 8단계 — Gatekeeper (안전 게이트) 🚫

**언제 보나**: 항상. 가장 먼저 체크.

**무엇을 보나**: 3가지 안전 검사:
- **뉴스** — 큰 사건/해킹/규제 발표 여부
- **경제** — FOMC, CPI 같은 발표 임박 여부
- **고래** — 비정상적 청산/이동 감지

**초보 사용법** — **이건 무조건 0순위**:

```
🟢 SAFE · GATE OPEN  → 진입 허용
🟡 PENDING           → 대기, 30초 후 재확인
🔴 BLOCKED           → 진입 절대 X. 다른 시간으로 미루기
```

**원칙**: 8단계가 빨강이면 **다른 모든 단계가 통과해도 진입 금지**.

---

### 9단계 — EXECUTE (최종 결정)

**언제 보나**: 다른 모든 단계 본 후 마지막 확인.

**무엇을 보나**: 종합 판단:

```
🚀 EXECUTE 활성       → 게이트 OPEN + 트리거 ON, 진입 가능
⏳ 게이트 OK · 트리거 대기 → 셋업은 좋으나 타이밍 X
🚫 트리거 OK · 게이트 차단 → 안전상 진입 금지
⏸ 대기 중            → 둘 다 미충족
```

**🚀 EXECUTE 활성** 떠야 진짜 진입.

## 5. 통합 대시보드 활용 — 9단계 한 화면에

좌측의 **`통합`** 탭이 기본 화면. 여기서 9단계의 상태가 카드 9개로 한눈에 보여요:

```
┌─────────┬─────────┬─────────┐
│1.거시   │2.차트   │3.멀티TF │
│  🟢 OK  │  🟡 대기│  🟢 OK  │
├─────────┼─────────┼─────────┤
│4.컨플    │5.OnChain│6.Trigger│
│  🟢 Tier S│ ⚪ 데이터│ ⏳ 3/4 │
├─────────┼─────────┼─────────┤
│7.AI     │8.Gate   │9.EXECUTE│
│  🟢 UP72%│ 🟢 SAFE │  ⏳ 대기 │
└─────────┴─────────┴─────────┘
                  ↑
        종합 점수: 82/100  진입 가능
```

**점수 해석**:
- **80~100**: 🚀 권장 — 매매 적극
- **65~79**: 👍 가능 — 일반 사이즈
- **50~64**: 🤏 신중 — 사이즈 1/2
- **30~49**: ⏸ 보류 — 패스
- **0~29**: 🚫 차단 — 절대 진입 X

처음에는 **80점 이상만** 진입하시면 더 안전합니다.

## 6. 진입하기 — 주문 패널 사용

9단계 EXECUTE가 활성화되면, 우측 주문 패널에서:

### Step 1: 방향 선택
- **LONG (매수)** — 가격 상승 예상
- **SHORT (매도)** — 가격 하락 예상

분류기 시나리오와 일치시키세요:
- bounce-up / break-up → LONG
- bounce-down / break-down → SHORT

### Step 2: 가격 (USDT)
- **현재가** — 시장가 진입 (간편)
- 직접 입력 — 지정가 진입 (정밀)

초보자: **현재가**로 시작. 익숙해지면 지정가.

### Step 3: 수량
- 직접 입력하지 마세요. **Risk %** 사용

### Step 4: Risk %, SL %, TP %

```
Risk %  1.0   ← 거래당 계좌의 1% 리스크 (전략 룰북 표준)
SL %    1.0   ← 손절가 = 진입가의 ±1%
TP %    2.0   ← 익절가 = 진입가의 ±2%
```

**REWARD : RISK 표시** = TP/SL 비율. 1:2 이상이어야 합니다.

### Step 5: 매수/매도 버튼

녹색 **매수/LONG** 버튼이 활성화되었는지 확인:

```
✅ 진입 가능 · 모든 게이트 체크 통과
```

이 메시지 뜨면 클릭. 즉시 페이퍼 포지션이 만들어집니다.

⚠️ **시뮬레이션 전용** 표시 확인 — 진짜 거래소 X.

## 7. 진입 후 관리

### 페이퍼 위젯이 모든 걸 자동 처리

우측 하단 위젯에서:

```
📊 페이퍼          정지 / 실행중   ▶/■  ▾
오늘:  3건 (2/1) +1.20% ($120)
누적:  47건 승률 57% PF 1.62 MDD -3.2%
한도:  일 3.8% 여유 / 주 9.4% 여유
보유:  AVAX LONG +0.42%
       BTC  LONG -0.15%
```

- **매 5초마다** 가격 fetch → SL/TP 감시
- **TP 도달** 시 자동 익절 ($+이익)
- **SL 도달** 시 자동 손절 (-1% 이내)
- **수수료/슬리피지** 자동 차감 (실 PnL)

### 본인이 직접 할 일

거의 없어요. 다만:

1. **차트 보면서 시장 큰 변화 감지** — 갑작스런 뉴스/덤프 시
2. **빠른 수동 청산 필요 시** — 콘솔 명령:
   ```javascript
   // 모든 자동 포지션 즉시 청산
   _autoTraderStop()
   ```
3. **자동매매 임계값 조정** (며칠 후):
   ```javascript
   // 더 빡빡하게
   _autoTrader.minStrength = 85
   _autoTrader.minClsConfidence = 75
   ```

## 8. 일일 루틴 — 추천 시간표

자동매매가 24시간 돌지만, 본인은 다음 시간에만 잠깐 확인:

### 🌅 아침 (07:00~08:00 KST)

- 어젯밤 결과 확인 (위젯 "오늘" 행, 자정에 리셋되니 어제 누적)
- **누적 KPI** 행 변동 확인 (승률, PF가 나빠지는 추세인가?)
- 거시 환경 1단계 — 오늘 매매할 만한 환경인가?

### 🌞 점심 (12:00~13:00 KST)

- 보유 포지션 상태 한 번 확인
- 미국장 개장 (22:30 KST) 직전 위험도 체크
- "한도" 행 — 일일 손실 여유 충분한가?

### 🌙 저녁 (21:00~23:00 KST)

- 미국장 변동성 큰 시간 — 보유 포지션 모니터링
- 23:00경 큰 손실 발생 시 직접 청산 고려

### 🛏️ 자기 전 (00:00~01:00 KST)

- 일일 결과 확인
- 03:00~06:00 KST는 자동 진입 차단 시간 (저유동성)
- 안심하고 주무세요

## 9. 주간 루틴 — 일요일 점검

매주 일요일 한 시간 정도 데이터 점검:

### 1️⃣ KPI 트렌드 분석

콘솔에서:

```javascript
// 이번 주 자동 매매 통계
_simComputeKpi({autoOnly: true, sinceTs: Date.now() - 7*24*3600*1000})
```

확인할 것:
- **n** ≥ 10건 (표본 충분?)
- **winRate** ≥ 0.55 (55% 이상?)
- **pf** ≥ 1.5 (Profit Factor 1.5 이상?)
- **maxConsecLoss** ≤ 4 (연속 손실 4 이하?)

### 2️⃣ 캘리브레이션 점검

위젯의 캘리브레이션 차트 확인:
- 80-89 버킷 적중률이 80% 근처인가? (분류기 신뢰성)
- 60-69 버킷이 60% 근처인가?

목표선과 막대가 크게 어긋나면 **임계값 더 높게** 조정.

### 3️⃣ 화이트리스트 검토

심볼별 성과 보기:

```javascript
['AVAXUSDT','ETHUSDT','BTCUSDT','SOLUSDT','LINKUSDT'].forEach(s =>
  console.log(s, _simComputeKpi({autoOnly:true, symbol:s}))
);
```

특정 심볼이 계속 손실이면 **scanner.symbols에서 제외**.

## 10. 절대 하지 말아야 할 것

### ❌ 1. SL 옮기기

진입할 때 정한 SL은 **절대 멀리 이동 X**. 손실 키우는 가장 흔한 실수.

### ❌ 2. "한 번만 더" 추격

자동매매가 SL 친 직후 같은 코인에 수동 진입하지 마세요. 백테스트 데이터에 없는 매매입니다.

### ❌ 3. 사이즈 키우기

일일 -3% 손실 후 "복구"하려 사이즈 두 배로 키우기. 도박이 됩니다.

### ❌ 4. 8단계 무시

8단계 빨강 표시인데 "이번 한 번만" 진입. 안전 게이트의 존재 이유가 무력화돼요.

### ❌ 5. 페이퍼 건너뛰고 실전

페이퍼 60건 미달인데 실전 자금 투입. 백테스트는 미래를 보장하지 않아요.

### ❌ 6. 숫자 자주 바꾸기

`minStrength`를 매일 조정. 통계가 누적될 시간을 안 줘요. **최소 2주 동일 설정 유지**.

## 11. 자주 묻는 질문 (FAQ)

### Q1. 위젯이 갑자기 사라졌어요

→ Watchdog이 자동 복원해요. 새로고침(Cmd+Shift+R)하면 다시 나타납니다.

### Q2. 자동매매가 한 거래도 안 해요

→ 임계값이 너무 빡빡한 상태. 정상이에요. **셋업 드물 때 안 들어가는 게 정답**입니다. 며칠 기다려도 0건이면:
```javascript
_autoTrader.scanner.enabled  // true 인가?
_autoTrader.enabled          // true 인가?
_autoTrader.minStrength      // 80 → 좀 낮춰볼지?
```

### Q3. 컨플루언스 존이 안 보여요

→ 4단계 탭 들어가서 `컨플루언스 존` 토글 ON. 또는 페이지 상단 차트 옵션 확인.

### Q4. 한 번에 몇 개 코인 보면 돼요?

→ scanner는 5개 자동 모니터링. 사용자는 **한 번에 한 코인 차트**만 봐도 OK. scanner가 모든 일을 합니다.

### Q5. 페이퍼 데이터가 사라질까 걱정돼요

→ localStorage에 영구 저장 + 1000건 아카이브. 다만 **브라우저 캐시 삭제 시 사라짐**. 중요하면 주기적으로:
```javascript
copy(JSON.stringify(_simAllTrades()))
```
콘솔 출력 → 백업 파일로 저장.

### Q6. 실전 전환 어떻게 하나요?

→ 전략 룰북 v1 (`docs/TRADING_STRATEGY_v1.md`)의 **"9. 실전 전환 체크리스트"** 따라가세요. 페이퍼 60건+ / 승률 55%+ / PF 1.5+ / MDD 8% 이하 모두 통과 후 첫 주는 **사이즈 20%로** 시작.

### Q7. 손실이 너무 빨리 나요

→ 일일 -5% 한도 자동 발동. 그래도 빠르면:
- 사이즈 0.5%로 축소 (`positionSizePct: 0.005`)
- 화이트리스트 1개 코인만 (`scanner.symbols = ['AVAXUSDT']`)
- 임계값 강화 (`minStrength = 90`, `minClsConfidence = 80`)
