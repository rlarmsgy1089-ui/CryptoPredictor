📅 2026-04-26 📖 약 25분 정독 🎯 매매 경험 0~1년

00이 도구가 뭐 하는 건가요?

한 줄: "여러 신호가 동시에 맞을 때만 매매하도록 사람을 도와주는 AI 보조 시스템".

매매 결정은 보통 한두 가지 신호로는 부정확해요. 이 도구는 9개의 독립된 검사를 통과한 셋업만 알려주고, 5개의 안전장치로 막대한 손실을 차단합니다. 페이퍼 트레이딩으로 먼저 검증한 후 실전으로 넘어가는 흐름을 권장해요.

⚠️
도구의 한계 먼저 알기

미래를 맞추는 도구가 아닙니다 — 확률 게임을 합리적으로 하는 도구예요. 백테스트 정확도 ~63%로, 100번 중 37번은 틀립니다. 가짜 돈 페이퍼에서 진짜 돈 실전으로 넘어가는 건 본인 책임이에요.

02처음 30초 — 시작 전 점검

페이지를 열자마자 본인이 매매해도 되는 환경인지 4초 안에 판단할 수 있어요.

✅ "지금 매매 가능" 신호

화면 우측 GATEKEEPER 패널이 초록색 SAFE · GATE OPEN 상태인지 확인:

GATEKEEPER true 🟢 SAFE · GATE OPEN 뉴스 경제 고래 🟢 🟢 🟢

세 등급(뉴스/경제/고래) 모두 🟢이면 시장이 정상입니다. 매매 진행 OK.

🚫 "지금 매매 위험" 신호

다음 중 하나라도 보이면 그 시간대는 신규 진입 자제:

  • GATEKEEPER가 빨강 ("DANGER" 또는 "BLOCKED")
  • 좌측 거시 컨텍스트에 🔴 RISK OFF 큰 빨간 글씨
  • 다음 주요 지표 D-0 또는 D-1 (FOMC, CPI 발표 1일 이내)
🚫
이런 경우엔 그냥 차트 구경만 하시거나, 보유 포지션 익절/손절 관리만 하세요. "다른 단계 다 통과했으니 한 번만"은 절대 금지.

04 ⭐ 컨플루언스 존 (가장 중요) CRITICAL
무엇을 보나
차트의 가로 줄들 — 여러 신호(피보나치, 거래량 프로파일, 패턴 경계, 이평선 등)가 같은 가격대에 겹친 구간

Tier 등급

Tierstrength적중률사용
🟢 Tier S≥ 8066%이것만 노리세요
🔵 Tier A≥ 50~58%보조용
⚪ Tier B≥ 30~53%사용 X (랜덤 수준)

4가지 진입 조건 (모두 AND)

  1. 녹색 Tier S 가로 줄이 차트에 있는지 확인
  2. 현재가가 그 존의 1.5% 이내인지 확인
  3. 분류기 라벨이 "반발 ↑" 또는 "반발 ↓" (bounce)인지 — "돌파"는 사용 X
  4. 분류기 confidence ≥ 65%
통과 예시

"BTC 현재가 $78,000, 컨플루언스 패널: '@77,800 Tier S strength=84 반발 ↑ conf=71%'"

✓ 거리 0.26%, Tier S, 반발, conf 71% → 모두 통과, 진입 후보

탈락 예시

"ETH 현재가 $4,200, '@4,150 Tier B strength=35 돌파 ↓ conf=52%'"

✕ Tier B + 돌파 시나리오 + 낮은 conf → 모두 탈락, 패스

06진입하기 — 주문 패널

9단계 EXECUTE가 활성화되면, 우측 주문 패널에서 5스텝.

  1. 1 방향 선택 — 분류기 시나리오와 일치
    bounce-up / break-up → LONG · bounce-down / break-down → SHORT
  2. 2 가격 (USDT) — 현재가(시장가) 또는 직접 입력(지정가)
    초보자: 현재가로 시작. 익숙해지면 지정가.
  3. 3 수량 — 직접 입력 X
    Risk %로 자동 계산되니 그냥 두세요.
  4. 4 Risk % / SL % / TP %
    Risk %  1.0   ← 거래당 계좌의 1% 리스크
SL %    1.0   ← 손절가 = 진입가의 ±1%
TP %    2.0   ← 익절가 = 진입가의 ±2%
    REWARD : RISK 비율 1:2 이상이어야 합니다.
  5. 5 매수/LONG 버튼 클릭
    "✅ 진입 가능 · 모든 게이트 체크 통과" 메시지 확인 후 클릭. 즉시 페이퍼 포지션 생성.
⚠️
시뮬레이션 전용 표시 확인 — 진짜 거래소 X. 페이퍼 트레이딩에서만 작동합니다.

08일일 루틴 — 추천 시간표

자동매매가 24시간 돌지만, 본인은 다음 시간에만 잠깐 확인.

🌅 07~08
아침 — 어젯밤 결과 확인 (위젯 "오늘" 행, 자정에 리셋되니 어제 누적 KPI 확인). 거시 환경 1단계 — 오늘 매매할 만한 환경인가?
🌞 12~13
점심 — 보유 포지션 상태 한 번 확인. 미국장 개장(22:30 KST) 직전 위험도 체크. "한도" 행 — 일일 손실 여유 충분한가?
🌙 21~23
저녁 — 미국장 변동성 큰 시간 — 보유 포지션 모니터링. 23시경 큰 손실 발생 시 직접 청산 고려.
🛏️ 00~01
자기 전 — 일일 결과 확인. 03~06 KST는 자동 진입 차단 시간(저유동성). 안심하고 주무세요.

09주간 루틴 — 일요일 점검

매주 일요일 한 시간 정도 데이터 점검.

1️⃣ KPI 트렌드 분석

// 이번 주 자동 매매 통계
_simComputeKpi({autoOnly: true, sinceTs: Date.now() - 7*24*3600*1000})

확인할 것:

  • n ≥ 10건 (표본 충분?)
  • winRate ≥ 0.55 (55% 이상?)
  • pf ≥ 1.5 (Profit Factor 1.5 이상?)
  • maxConsecLoss ≤ 4 (연속 손실 4 이하?)

2️⃣ 캘리브레이션 점검

위젯의 캘리브레이션 차트 확인:

  • 80-89 버킷 적중률이 80% 근처인가? (분류기 신뢰성)
  • 60-69 버킷이 60% 근처인가?
  • 목표선과 막대가 크게 어긋나면 임계값 더 높게 조정

3️⃣ 화이트리스트 검토

['AVAXUSDT','ETHUSDT','BTCUSDT','SOLUSDT','LINKUSDT'].forEach(s =>
  console.log(s, _simComputeKpi({autoOnly:true, symbol:s}))
);

특정 심볼이 계속 손실이면 scanner.symbols에서 제외.

10절대 하지 말아야 할 것

  • SL 옮기기 진입할 때 정한 SL은 절대 멀리 이동 X. 손실 키우는 가장 흔한 실수.
  • "한 번만 더" 추격 자동매매가 SL 친 직후 같은 코인에 수동 진입하지 마세요. 백테스트 데이터에 없는 매매입니다.
  • 사이즈 키우기 일일 -3% 손실 후 "복구"하려 사이즈 두 배. 도박이 됩니다.
  • 8단계 무시 8단계 빨강인데 "이번 한 번만" 진입. 안전 게이트의 존재 이유가 무력화됩니다.
  • 페이퍼 건너뛰고 실전 페이퍼 60건 미달인데 실전 자금 투입. 백테스트는 미래를 보장하지 않아요.
  • 숫자 자주 바꾸기 minStrength를 매일 조정. 통계가 누적될 시간을 안 줘요. 최소 2주 동일 설정 유지.

11자주 묻는 질문

위젯이 갑자기 사라졌어요

Watchdog이 자동 복원해요. 새로고침(Cmd+Shift+R)하면 다시 나타납니다. 문제 지속 시 콘솔에 document.getElementById('paperWidget') 입력해서 DOM 존재 여부 확인.

자동매매가 한 거래도 안 해요

임계값이 너무 빡빡한 상태. 정상이에요. 셋업이 드물 때 안 들어가는 게 정답입니다. 며칠 기다려도 0건이면:

_autoTrader.scanner.enabled  // true 인가?
_autoTrader.enabled          // true 인가?
_autoTrader.minStrength      // 80 → 좀 낮춰볼지?
컨플루언스 존이 안 보여요

4단계 탭 들어가서 컨플루언스 존 토글 ON. 또는 페이지 상단 차트 옵션 확인.

한 번에 몇 개 코인 보면 돼요?

scanner는 5개 자동 모니터링. 사용자는 한 번에 한 코인 차트만 봐도 OK. scanner가 모든 일을 합니다.

페이퍼 데이터가 사라질까 걱정돼요

localStorage에 영구 저장 + 1000건 아카이브. 다만 브라우저 캐시 삭제 시 사라짐. 중요하면 주기적으로:

copy(JSON.stringify(_simAllTrades()))

콘솔 출력 → 백업 파일로 저장.

실전 전환 어떻게 하나요?

전략 룰북 v1 (docs/TRADING_STRATEGY_v1.md)의 "9. 실전 전환 체크리스트" 따라가세요. 페이퍼 60건+ / 승률 55%+ / PF 1.5+ / MDD 8% 이하 모두 통과 후 첫 주는 사이즈 20%로 시작.

손실이 너무 빨리 나요

일일 -5% 한도 자동 발동. 그래도 빠르면:

  • 사이즈 0.5%로 축소 (positionSizePct: 0.005)
  • 화이트리스트 1개 코인만 (scanner.symbols = ['AVAXUSDT'])
  • 임계값 강화 (minStrength = 90, minClsConfidence = 80)
