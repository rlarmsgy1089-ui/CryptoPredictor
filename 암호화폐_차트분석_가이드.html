Chapter 01

이 도구는 무엇인가

BTC · ETH · SOL 의 단기 방향(오를지/내릴지)을 확률로 알려주는 개인용 대시보드. 네 Mac 에서 15분마다 자동으로 돌아가면서 Binance 공개 시세·펀딩비·미결제약정(OI)·공포탐욕지수 등을 수집하고, XGBoost 머신러닝 모델이 학습한 패턴으로 15분/1시간/4시간 뒤의 가격 방향을 예측해.

✅ 이 도구가 할 수 있는 것

  • 15분~4시간 단기 방향(상승/하락/중립) 확률 계산
  • 현재 시장이 추세장인지 횡보장인지 자동 감지 (레짐)
  • 모델이 과거 데이터에서 얼마나 맞췄는지 지속 추적 (드리프트)
  • 백테스트로 여러 전략을 과거 구간에 돌려 성과 비교
  • 지지·저항 레벨, 차트 패턴(삼각수렴·쐐기 등) 자동 표시
  • 청산맵·공포탐욕·펀딩비 등 외부 시그널 집계

❌ 이 도구가 하지 않는 것

  • 실제 주문 · 거래 자동화 (트레이딩 봇 아님. 거래소 API 키도 안 받음)
  • "반드시 오른다/내린다" 같은 확정 예언
  • 뉴스·이벤트·블랙스완 예측
  • 장기(일/주/월) 가격 목표 예측
  • 네가 감당할 수 없는 포지션 사이즈 추천
예측은 "확률적 참고 자료" 다
모델 정확도가 52% 면, 100번 중 52번 맞춘다는 뜻이야. 한 번 틀리는 건 문제가 아니다 — 오히려 당연한 일. 중요한 건 수백 번 반복했을 때 평균이 유리한가(기댓값 > 0) 인지. 그래서 리스크 관리(손절, 포지션 사이즈) 가 예측 정확도보다 더 중요해.

Chapter 03

매일 사용 루틴 — 투자자 관점

"이 도구를 실제로 어떻게 굴려 써?" 에 대한 답. 기술 설명이 아니고, 투자자가 하루 중 언제 / 뭘 보는지 정리한 실무 루틴이야.

3.1 아침 5분 체크리스트

일어나자마자 브라우저 열고 아래 순서대로 훑어봐.

01
as_of 시각 확인
AI 예측 탭 상단. 지금 시각으로부터 20분 이내면 정상. 넘어가면 자동화가 멈춘 것 — status.command 실행.
02
3개 호라이즌 방향
15m/1h/4h 모두 UP 이면 매수 편향, 모두 DOWN 이면 매도 편향. 섞이면 혼조 — 관망.
03
레짐 확인
high_vol(고변동): 포지션 축소. range: 돌파 대기. trend_up/down: 추세 따라가기.
04
드리프트 배지
빨간 "재학습 권장" 배지 있으면 주의. 해당 호라이즌 신뢰도 한 단계 낮춰 봐.
05
시장 온도계
공포탐욕 80+: 조정 가능. 20-: 반등 가능. 펀딩비 비정상 +: 롱 과밀 → 단기 조정 위험.

3.2 진입 판단 순서 (의사결정 트리)

"사도 될까?" 라는 질문이 생기면, 아래 5단계를 순서대로 통과시켜. 하나라도 막히면 그날은 진입 보류.

추세 정렬
15m · 1h · 4h 방향이 최소 2개 이상 같은 방향 인가? (예: 15m UP + 1h UP + 4h NEUTRAL)
확률 최소 기준
1h 또는 4h 에서 prob_up ≥ 0.58 또는 ≤ 0.42 인가? 0.55 미만은 노이즈와 구분 안 됨.
레짐 궁합
현재 레짐이 내 트레이드 스타일과 맞나? (돌파 매수면 range 탈출 or trend 확립 때, 평균회귀면 range 중간대)
외부 시그널 상충 여부
공포탐욕 극단 / 펀딩비 극단 / OI 급증 이 내 방향과 반대 로 가면 재고. (예: 예측 UP인데 공포탐욕 85 + 펀딩비 +0.1% → 롱 피로)
리스크 관리 확정
SL 가격 결정 → 손실 % 계산 → 포지션 사이즈 역산. SL 없이 진입은 도박. 도구의 suggested_sl_pct 참조, 무조건 같을 필요는 없음.
통과 못하는 날이 더 많다는 게 정상
5단계를 깐깐하게 돌리면 하루에 0~1회 진입이 평범해. 거래 빈도가 수익의 적. 기회가 없으면 아예 하루 안 들어가는 것도 훌륭한 의사결정.

3.3 포지션 중 관리

진입 후엔 도구의 역할이 바뀜 — "예측 확인" 이 아니라 "가설 검증" 이 됨.

  • 매 15분 갱신될 때마다 내 포지션 방향과 예측이 계속 일치하는지 확인.
  • 예측 방향이 반대로 바뀌었으면 (UP→DOWN) 가설 붕괴 — 손절 or 절반 이익 실현 고려.
  • 레짐이 바뀌면 (range → high_vol) 변동성 확대 → SL 여유 넓히거나 포지션 축소.
  • 드리프트 플래그가 떴으면 목표 이익 축소 (모델 신뢰도가 낮아진 상태).

3.4 청산 · 재평가

  • TP 도달: 계획대로 청산. 욕심 부리지 말고 일부만 남겨도 OK.
  • SL 도달: 감정 없이 청산. "조금만 기다려 보자" 가 계좌 파괴 1순위.
  • 시간 초과: 4h 예측 진입이면 4h 후에도 방향 안 나오면 기회비용 — 청산 후 재진입 기회 탐색.
  • 매매 후 기록: 진입 사유 · 예측값 · 청산 사유 · 결과를 적어두면 네 판단의 드리프트도 볼 수 있음.

화면 투어 — 6개 탭 가이드

상단 탭 6개를 왼쪽에서 오른쪽 순서로 설명할게. 투자 결정엔 AI 예측 탭 이 중심이고 나머진 보조야.

Tab 1 지표 요약 (기본값)
용도현재 가격 · 변동률 · 거래량 · 주요 이동평균 · RSI · MACD · 볼린저밴드 한눈에. 언제 보나가장 먼저 열어서 "지금 이 코인이 어디쯤 있는지" 감 잡을 때.
주요 지표
  • 현재가 vs MA20/MA50/MA200: 위에 있으면 상승 구조, 아래면 하락 구조
  • RSI(14): 70+ 과매수, 30- 과매도 (단, 강추세에선 오래 머무름)
  • MACD: 0선 위아래와 히스토그램 방향
  • BB 위치: 상단 돌파·하단 돌파 시점은 변동성 확대 신호
Tab 2 패턴 인식
용도삼각수렴·쐐기·헤드앤숄더 등 클래식 차트 패턴 자동 검출. 언제 보나수동 차트 보기 싫을 때, 큰 그림 구조 확인할 때.
주요 지표
  • 패턴 신뢰도: 높을수록 교과서적 — 낮으면 모양만 비슷할 수 있음
  • 돌파 예상 방향: 패턴이 시사하는 결말
  • 측정 가격: 패턴 달성 시 예상 목표가 (참고만)
Tab 3 AI 예측 ★ 가장 중요
용도XGBoost 기반 방향·확률 예측. 이 도구의 핵심. 언제 보나하루 중 가장 자주 보는 탭. 진입/청산 판단의 중심.
주요 지표
  • 15m/1h/4h PRO 예측 카드: 방향 · 확률 · 기대 수익 · SL 제안
  • 신뢰도 / 안정성: 확률 얼마나 믿을지 보조 지표
  • 레짐: 현재 시장 상태 (4가지)
  • 라이브 모델 성능: 최근 실제 히트율 vs 백테스트 히트율 (드리프트)
  • 시장 온도계: 공포탐욕 / 펀딩비 / OI 등 외부 시그널
Tab 4 백테스팅
용도전략을 과거 구간에 돌려 "얼마나 벌었을까?" 시뮬레이션. 언제 보나새 전략 아이디어 테스트할 때, "진짜 이게 먹혔나?" 검증할 때.
주요 지표
  • 전략 종류: MA 크로스, RSI 반전, MACD, BB, 삼중 확인 등
  • 초기 자본 · 수수료: 실제 거래소 조건과 맞춰야 의미 있음
  • 결과 지표: 수익률 · 최대 낙폭(MDD) · 샤프 · 승률 · 거래 횟수
  • HTF 필터: 상위 타임프레임 추세와 같은 방향일 때만 매매
MDD 50% 넘는 전략은 실전에서 버티기 어려움. 수익률만 보지 말 것.
Tab 5 온체인
용도거래소 유입량, 대규모 이체 등 온체인 이벤트 추적. 언제 보나주봉 이상 큰 그림 판단할 때. 단타엔 큰 영향 없음.
주요 지표
  • 거래소 유입: 급증 시 매도 압력 가능성
  • 대형 지갑 이동: 고래 활동 감지
Tab 6 사용법 (도구 내장)
용도브라우저 안에 들어있는 간단 안내. 이 가이드가 더 자세함. 언제 보나링크 확인용.

AI 예측 탭 심층 해석

이 도구의 핵심 화면. 각 필드가 무슨 뜻인지, 어떻게 조합해서 읽는지 정리.

5.1 PRO 예측 카드 4개 필드

15m / 1h / 4h 각 호라이즌마다 카드 하나씩. 각 카드는 4가지 핵심 필드를 담고 있어.

direction
UP · DOWN · NEUTRAL
prob_up 0.55+ → UP, 0.45- → DOWN, 그 사이 → NEUTRAL
prob_up
0.00 ~ 1.00
50%는 동전던지기. 55%+ 의미, 60%+ 강한 신호.
expected_move_pct
±0.00%
만기까지 예상 가격 변동률. 음수면 UP 예측이어도 하락 기댓값.
suggested_sl_pct
0.00%
모델이 계산한 권장 손절 폭. high_vol에선 커짐. 본인 성향에 맞게 조정.
확률 읽기 주의
63% 는 "절대 올라간다" 가 아니고 "100번 중 63번 올랐다" 는 과거 패턴 기반 추정. 즉 37번은 틀린다는 뜻. 1회 결과로 모델을 평가하지 말 것. 수십 회 평균을 봐야 의미 있음.

5.2 신뢰도 · 안정성 · 레짐

필드의미
accuracy_wfv Walk-Forward 검증 정확도. "과거에 이 모델이 이 호라이즌에서 얼마나 맞췄나." 15m 은 52~55%, 4h 는 53~58% 가 일반적. 50% 근처는 가치 없음.
accuracy_std 정확도의 표준편차. 작을수록 꾸준. 0.02 이하: 안정 / 0.02~0.05: 보통 / 0.05+: 변동성 큼 → 신뢰 낮춤.
regime 시장 상태 4가지 (아래 박스).

5.3 라이브 모델 성능 (드리프트)

여기가 이 도구의 가장 중요한 자기 점검 장치. 모델이 만든 예측이 실제 시장에서 얼마나 맞는지, 백테스트 때와 괴리 없이 가고 있는지 보여줘.

핵심 숫자 3개

지표설명
live_rate최근 라이브 예측 중 실제로 맞춘 비율. 예: 0.52 = 52%.
wfv_rate같은 호라이즌의 백테스트(Walk-Forward) 정확도. "원래 이만큼 맞춰야 한다" 는 기준선.
driftlive - wfv 차이. 0 에 가까울수록 건강. -5%p 넘으면 주의, -7%p 넘고 3회 연속이면 재학습 권장.

재학습 권장 배지 해석

insufficient_data
라이브 샘플 부족 (n<20). 아직 측정 불가. 기다려.
ok
정상. 모델이 기대대로 동작 중.
warn
1회 단발 드리프트. 경계하되 아직 급한 조치 불필요.
critical
연속 3회 이상 기준치 초과. 이 호라이즌 예측 신뢰도 낮춰서 봐.
critical 이 뜨면 어떻게?
(1) 해당 호라이즌 진입 보류 or 사이즈 축소
(2) 며칠 관찰 후 자연 회복되는지 확인
(3) 지속되면 재학습 실험 (experiments/ 폴더의 proposals.json + runner.py)
네가 지금 사용 중인 v1.2.0 은 그 과정을 이미 한 번 거친 결과물이야.

5.4 시장 온도계 (외부 시그널)

지표해석 기준
공포탐욕지수0~100. 0~25 극단공포(역발상 매수 고려) / 25~50 공포 / 50~75 탐욕 / 75~100 극단탐욕(조정 가능성).
펀딩비8시간마다 결제되는 롱·숏 균형 지표. +0.03% 이상: 롱 과밀 → 조정 위험. 음수: 숏 과밀 → 숏스퀴즈 가능.
미결제약정 (OI)총 열린 포지션 수. 급증 + 가격 상승: 추세 확립. 급증 + 가격 횡보: 방향 불안정, 변동성 폭발 대기.

Chapter 06

시스템 건강 체크

이 도구는 자동으로 돌아가지만 방치하면 안 돼. 아래 주기에 맞춰 최소한의 점검을 해주면 오래 건강하게 쓸 수 있어.

6.1 매일 — 30초

  • 브라우저 열어서 as_of 가 20분 이내 인지 확인 (자동 실행 살아있는지).
  • 재학습 권장 배지가 critical 로 바뀌지 않았는지.
  • predictions 파일 심볼별로 전부 최신인지 (BTC/ETH/SOL).

6.2 매주 — 5분

  • predictor/automation/status.command 더블클릭 → 실행 로그 10줄 훑기.
  • logs/run_auto.log 파일 크기 확인. 5MB 넘으면 자동 로테이션되지만 수동으로 지워도 됨.
  • 드리프트 히스토리 차트(UI) 한 번 열어서 추세 확인 — 악화 중인지 안정 중인지.
  • 주간 거래 일지 작성 — 내 진입이 예측 신뢰도 대로 작동했는지 돌아봄.

6.3 매월 — 15분

  • logs/ 폴더 크기 체크. 수백 MB 되면 오래된 월별 로그 정리.
  • requirements.txt 에 업데이트 있는지 체크 (보안 패치 목적). 없으면 업데이트 불필요.
  • Binance API 응답이 여전히 정상인지 (Binance 가 API 스펙 바꾸면 코드 수정 필요).
  • 내 거래 성적 vs 예측 동의율 비교. 예측대로 안 하는 경우가 많으면 시스템 의심 전에 내 훈육 을 먼저.

Chapter 07

자주 하는 실수와 교훈

초보 투자자가 이 도구를 쓰며 가장 흔히 저지르는 실수들. 먼저 알고 들어가면 피할 수 있어.

"확률 63% 니까 무조건 들어간다"
63% 는 37% 확률로 틀리는 것. 손절 없이 진입하면 37% 가 계좌의 100% 손실 로 번역됨. 확률은 진입 여부가 아니라 포지션 사이즈·손익비 계산에 쓰는 재료.
1회 틀렸다고 모델 버림
예측기는 "1번 중 1번 맞추는 것" 이 아니라 "100번 중 52번 맞추는 것". 최소 30~50회 이상 샘플에서 히트율 평가해야 의미 있음.
4h 예측 하나만 보고 스캘핑
호라이즌과 매매 시간이 안 맞음. 스캘핑은 15m, 포지션 트레이딩은 4h 가 주 신호. 자기 스타일에 맞는 호라이즌 하나를 주력으로 정해.
백테스트 수익률 300% 전략 바로 실전
MDD 60% 인 걸 몰라서 5% 손실에 손절, 실전 손익은 -50%. MDD · 거래 횟수 · 샤프를 먼저 보기.
드리프트 critical 뜬 상태로 계속 거래
모델이 "나 지금 틀리고 있어요" 라고 경고하는 상태. 사이즈 축소 또는 해당 호라이즌 일시 배제 가 정석.
자동화 설치하고 Mac 잠자기 설정
launchd 는 잠자는 Mac 을 못 깨움. 예측 멈춘 채 UI 만 옛 데이터 표시. 전원 어댑터 연결 시 "잠들지 않기" 설정 필수.
공포탐욕/펀딩비 극단값을 역방향 신호로 맹신
극단값이 더 극단으로 가는 경우도 많음. 가격 행동과 함께 봐야 함. (예: 공포탐욕 15 + 지지선 지켜짐 = 반등 신호, 공포탐욕 15 + 지지선 붕괴 = 추가 하락)
Chapter 08

용어 사전 (가나다순)

도구를 쓰며 마주칠 핵심 용어 모음. 처음 보는 단어는 여기서 빠르게 찾아봐.

용어뜻
공포탐욕지수Fear & Greed Index. 0~100 의 시장 심리 지표. 극단값은 역방향 신호로 자주 쓰임.
드리프트Drift. 라이브 히트율 - 백테스트 히트율. 음수가 커지면 모델 노후화 의심.
레짐Regime. 시장 상태 분류 (trend_up/down, range, high_vol). 모델이 자동 감지.
롱숏비율Long/Short Ratio. 열린 롱 포지션 / 숏 포지션 수. 극단치는 반대 청산 유발.
미결제약정Open Interest(OI). 현재 시장에 열려있는 전체 선물 포지션 수량.
백테스트Backtest. 과거 데이터로 전략의 수익률을 시뮬레이션.
샤프 비율Sharpe Ratio. (평균 수익 - 무위험 수익) / 수익의 표준편차. 1 이상이면 양호.
손절 (SL)Stop Loss. 손실 한도에 도달하면 자동 청산하는 주문.
순이익 비율Expectancy. 평균 승리 × 승률 - 평균 손실 × 패율. 양수여야 살아남음.
익절 (TP)Take Profit. 목표 수익에 도달하면 자동 청산하는 주문.
챔피언 모델현재 프로덕션에 쓰이는 모델 버전. 현 v1.2.0 (2026-04-19 승격).
켈리 공식Kelly Criterion. 확률·손익비로 최적 베팅 사이즈 계산. 실전은 1/4 켈리 권장.
펀딩비Funding Rate. 8시간마다 영구선물 롱·숏 간 결제되는 수수료. 방향 과밀 지표.
호라이즌Horizon. 예측 대상 시간 (15m / 1h / 4h).
히트율Hit Rate. 예측이 실제 방향과 맞은 비율.
WFVWalk-Forward Validation. 시계열 데이터에 맞는 백테스트 방식. 미래 정보 누출 방지.
XGBoost그라디언트 부스팅 트리 기반 머신러닝 알고리즘. 이 도구의 예측 엔진.
MDDMaximum Drawdown. 전략의 최대 누적 손실폭. 실전 견딜 수 있는지 판단 기준.
